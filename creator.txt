Python IS Needed, (if you didnt install it already, it is needed for duckdrop's Main File.)


Open CMD,

Type 'pip install PyInstaller',

Then 'python -m PyInstaller --noconsole --onefile duckdrop.py'


----

It should be in a folder named 'dist', it should be in there.
